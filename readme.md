# Godot stuff

Mostly for the convience when it comes to version control and scale,
this is a monorepo containing (most) of the Godot projects I'm working on.

Some of these are experiemnts learning how Godot/GDScript works, others
are just because I was bored and Godot happens to be one of my favorite 
runtimes.

## Games
- `snake-test`: Concise snake clone, more as a test to see how little
  it takes to write a functional game in Godot.
  
- `map-test`: Uses Perlin noise to create a platform. Has a funny little guy.
